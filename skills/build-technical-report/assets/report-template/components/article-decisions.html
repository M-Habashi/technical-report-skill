Predeclare acceptance gates

A method passes only when performance, feasibility, and robustness hold together.

Accept

Lower worst-condition tracking error on endpoints and holdout with no command, rate, or stability violation.

Reject or reposition

The result depends on one endpoint, violates the actuator limit, or disappears when the deployed loop is included.

The next experiment should decide something

A compact experiment is stronger than a wide parameter sweep with no frozen hypothesis.

  1. Collect one intermediate operating-condition dataset for model selection.
  2. Freeze the model, objective, baseline, and acceptance metrics.
  3. Collect a second intermediate condition as a blind holdout.
  4. Run identical endpoint and holdout simulations before physical testing.
  5. Publish per-condition results, the worst case, and all failed gates.
