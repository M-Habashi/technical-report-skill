Make the model, equation, and verification path inspectable

A method article should let another engineer reproduce the calculation and identify exactly where assumptions enter.

Method rule

Use the simplest model that explains the measured change, then test the assumption that makes it simple.

Verification is part of the method

Report the checks needed to reject the conclusion, not only those expected to pass.

  1. Verify units, coordinate definitions, and model stability before synthesis.
  2. Reserve one operating condition and one excitation as blind holdouts.
  3. Compare every method with identical command, rate, delay, and noise conditions.
  4. Recalculate metrics from exported signals rather than trusting plot labels.
  5. Reject the hypothesis if the improvement disappears on the holdout.
